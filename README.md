# Структура файлов проекта "Морской Бой"

1. **index.html** - Разметка. Запускайте этот файл в браузере.
2. **style.css** - Стили. Оформление панели, кнопок, счетчиков и CRT-фильтр.
3. **game.js** - Игровая логика (движок, свайп, стрельба).
4. **images/** - В эту папку мы положим нарисованные картинки:
   - `panel.png` - железная панель с дыркой (UI)
   - `bg_sea.jpg` - длинная панорама моря
   - `ship1.png` - спрайт дальнего корабля
   - `ship2.png` - спрайт подводной лодки и т.д.

Откройте эту папку в VS Code. Для локального тестирования лучше использовать плагин "Live Server".
